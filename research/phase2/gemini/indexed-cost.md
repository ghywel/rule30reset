# W5 · What a structural lower bound can buy on the named centre

An aperiodicity proof for the actual singleton centre would immediately give a machine-time partial. In every canonical dyadic window, some index forces any correct one-tape machine to reach digit position k and take at least k+1 steps. This is logarithmic in the numeric index. It applies if the unbounded marked births of Q2 or Galindo's vocabulary criterion are established. Full Q01, if established via W1, would rule out eventual period two. To use the canonical-window conclusion at every scale one needs, for example, all eventual periods 2ᵏ excluded for the named column. Jen's two-column theorem leaves open which member of the pair is aperiodic. **A sharp control in the official tape model.** Put b(n) equal to the parity of the binary digit length of n, taking length zero for zero. A two-state machine flips state on every digit and reports its state on the first blank. Lean proves that it computes b at all n in exactly the allowed time length(n)+1. Conversely, appending a new leading one at n+2^length(n) flips b without altering any old digit. The kit's ray-flip lower bound forces **every** correct machine to take at least length(n)+1 steps on **every** positive n. Thus even the strongest distribution of these blank-reaching witnesses is compatible with logarithmic time. The same control is aperiodic and has unbounded constant runs of both colours. To break a proposed period P arbitrarily late, choose a large power of two and compare its first tick with the tick P before it in the preceding colour block. [Core Lean scanner, aperiodicity and optimality](LengthControl.lean)

Balance can be imposed too. For the classical Thue–Morse sequence, the bits at 2n and 2n+1 are complements, so every even-length prefix has density exactly one half. Its digit-sum formula gives a two-state scanner that toggles on each 1 rather than each digit. A new leading one always flips the output, giving the same exact positive-input cost. For a proposed period P, compare 2ᵏ−1 and 2ᵏ−1+P at large k. The first bit is k modulo two; the second is one minus the bit at P−1. One parity of k breaks the period arbitrarily late. This is a hand-checked comparison. It shows why aperiodicity, exact balance and arbitrarily deep input-digit distinctions together still allow logarithmic lookup. [Allouche and Shallit, Proposition 1](https://cs.uwaterloo.ca/~shallit/Papers/ubiq15.pdf)

**The unit of time matters.** In the Hennie–Trakhtenbrot unary equivalence, the input has n symbols. On digit inputs the kit uses fast deciders for **both** base 2 and base 3 to characterize eventual periodicity. The small-time threshold uses the length of the encoded string. Problem 3 feeds one binary index to a fixed machine and asks to rule out all time bounds C(n+1) in the numeric n. A machine that scans the whole binary input has used about log₂ n steps. The missing argument would have to force work beyond even a linear number of steps in the numeric index. The quantifier over distinct input rows supplies distinguishable prefixes in the state-count argument. On the singleton the machine instead receives the binary digits of the age and may use a read/write tape. A transfer would need a reduction encoding those distinguishable instances in singleton indices, with proof of output agreement and appropriate cost.

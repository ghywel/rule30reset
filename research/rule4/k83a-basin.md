This classifies the seeded sample under the prescribed alternating wall. The fair-coin probability of the exceptional set is open.

A sample is a white tick of the black-first wall. Sample zero is physical tick one. At each white sample the computation tests the kit's exact spatial windows, with bit zero at site 1. The 30- and 45-cell seven-locks have 66 and 33 windows respectively, split into seven perpetually advancing phases. The ether certificate uses a matching prefix of 6 + 7j cells followed by one of the kit's same-phase 13-cell wall states, testing j from 0 through 6. These finite criteria certify the entire future of the gate. The trap certifies that every future gap between black readings is 3 or 5. A trapped gate can itself be periodic. ## Reproduction

Compile [the cohort replay](k83a-basin.cpp) and [the cylinder counter](k83a-basin-cover.cpp) with `g++ -O3 -std=c++17 -fopenmp`, and [the atom counter](k83a-basin-atoms.cpp) with `g++ -O3 -std=c++17`. Set `PYTHONUTF8=1` on Windows. Run these commands with the three executable paths and an output directory of your choice.

```text
python research/rule4/k83a-basin.py BASIN OUT/600 --atoms ATOMS --cover COVER
python research/rule4/k83a-basin.py BASIN OUT/1200 --ids OUT/600/unresolved.txt --samples 1200
python research/rule4/k83a-basin.py BASIN OUT/2400 --ids OUT/600/unresolved.txt --samples 2400
python research/rule4/k83a-basin.py BASIN OUT/4800 --ids OUT/600/unresolved.txt --samples 4800
```

The driver rebuilds the spatial tables from the kit, checks the known 1891 and 3793493 entries, checks lock closure under all two-bit eastern extensions, and independently replays selected rows in arbitrary-precision integers. The baseline has 60 scalar controls, including one from every nonempty certificate/period bin. Each later run starts from the same row indices and regenerates every additional spatial bit from the original SplitMix stream.

The raw per-row records, index lists, census outputs and sources are in `share-scratch/gptIntel/K83A/basins.zip`, SHA-256 `de1b2d19315091a054edc07f2db2547b983903a618205e50d3028d5a220f88e7`.
